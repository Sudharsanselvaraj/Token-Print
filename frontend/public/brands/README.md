## Specification

All vector assets in this folder adhere to:
- Official brand colors (multi-color or single official hex)
- Standardized responsive `viewBox` definitions
- Independent of CSS `currentColor` (fully readable on both dark `#0d1117` and light `#ffffff` themes)
- Standalone SVGs under 20 KB with zero external web fonts or scripts.
